Tags in tables, lists, cards and boards link to their tag pages (community PR #18), the static equivalent of Obsidian's tag pills: `tags`, `note.tags` and `file.tags` columns, and tag values returned by formulas (`file.tags[0]`), show each tag without `#` and in its original case. Without tag pages (the tag-page plugin disabled), or for a value that is not a valid tag, a tag is plain text.
